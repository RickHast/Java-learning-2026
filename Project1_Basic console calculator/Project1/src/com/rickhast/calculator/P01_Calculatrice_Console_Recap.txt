OBJECTIF DU PROJET
──────────────────
Créer une calculatrice en ligne de commande (console) capable d'effectuer
les 4 opérations arithmétiques de base (+, -, *, /) avec gestion complète
des erreurs de saisie et boucle de relance.

FONCTIONNALITÉS DÉVELOPPÉES
────────────────────────────
  ✅ Saisie de deux nombres réels (type double)
  ✅ Saisie et validation de l'opérateur (+, -, *, /)
  ✅ Calcul et affichage du résultat formaté à 2 décimales
  ✅ Gestion de la division par zéro (message d'erreur + arrêt propre)
  ✅ Gestion des saisies invalides (try/catch + vidage du buffer)
  ✅ Boucle do/while : l'utilisateur peut enchaîner plusieurs calculs
  ✅ Fermeture propre du Scanner en fin de programme

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 1 — Scanner (java.util.Scanner)                             │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  Permet de lire les entrées de l'utilisateur depuis la console.

SYNTAXE :
  Scanner scanner = new Scanner(System.in);
  double  valeur   = scanner.nextDouble();   // lit un double
  String  texte    = scanner.next();          // lit un mot
  String  ligne    = scanner.nextLine();      // lit une ligne entière

POINT CLÉ — Le buffer :
  Quand nextDouble() échoue (saisie invalide), le token invalide reste
  dans le buffer. Il faut appeler scanner.nextLine() pour le vider,
  sinon la prochaine lecture relit le même token → boucle infinie.

BONNE PRATIQUE :
  Toujours appeler scanner.close() en fin de programme pour libérer
  la ressource.

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 2 — switch / case / break                                   │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  Remplace une longue chaîne de if/else if quand on teste une variable
  contre plusieurs valeurs fixes.

SYNTAXE :
  switch (variable) {
      case "valeur1":
          // code
          break;       // ← OBLIGATOIRE pour stopper l'exécution
      case "valeur2":
          // code
          break;
      default:
          // cas non prévu
  }

ERREUR CLASSIQUE — Fall-through :
  Sans break, Java continue d'exécuter les case suivants même s'ils
  ne correspondent pas. C'est le "fall-through bug".

  Exemple : si case "+" n'a pas de break, Java exécute aussi
  case "-", case "*", case "/" → résultat faux.

VERSION MODERNE (Java 14+) — Switch Expression :
  result = switch (operator) {
      case "+" -> number1 + number2;
      case "-" -> number1 - number2;
      case "*" -> number1 * number2;
      case "/" -> number1 / number2;
      default  -> 0.0;
  };
  // Pas besoin de break — la flèche -> l'implique

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 3 — Boucle do/while                                         │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  Exécute un bloc de code AU MOINS UNE FOIS, puis répète tant que la
  condition est vraie. Idéal pour les menus interactifs.

SYNTAXE :
  do {
      // code exécuté au moins une fois
  } while (condition);

DIFFÉRENCE AVEC while :
  while  → vérifie la condition AVANT d'entrer dans la boucle
  do/while → vérifie la condition APRÈS la première exécution

DANS CE PROJET :
  do {
      // calcul + saisie
      System.out.print("New calculation? (y/n): ");
      userChoice = scanner.next();
  } while (userChoice.equalsIgnoreCase("y"));
  // equalsIgnoreCase → accepte "Y" et "y"

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 4 — try/catch et gestion des exceptions                     │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  Intercepter les erreurs d'exécution (exceptions) pour éviter que
  le programme plante.

SYNTAXE :
  try {
      // code qui peut échouer
      double nombre = scanner.nextDouble(); // peut lancer une exception
  } catch (InputMismatchException e) {
      // code exécuté si l'exception se produit
      System.out.println("Erreur : " + e.getMessage());
      scanner.nextLine(); // vider le buffer
  }

DIFFÉRENCE :
  e.toString()     → affiche "java.util.InputMismatchException: message"
  e.getMessage()   → affiche uniquement "message" (plus propre)

BONNE PRATIQUE :
  Ne jamais laisser un catch vide. Toujours afficher au minimum
  e.getMessage() pour comprendre l'erreur.

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 5 — System.out.printf et formatage                          │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  Afficher du texte formaté avec un contrôle précis de l'apparence
  (nombre de décimales, alignement, etc.)

SYNTAXE :
  System.out.printf("format", valeur1, valeur2, ...);

SPÉCIFICATEURS UTILES :
  %.2f  → nombre décimal avec 2 chiffres après la virgule
  %d    → nombre entier
  %s    → chaîne de caractères
  %n    → saut de ligne (portable : fonctionne sur Windows, Linux, Mac)
  \n    → saut de ligne (peut poser problème sur Windows)

DIFFÉRENCE printf vs println(String.format(...)) :
  // ❌ Double appel — inutilement verbeux
  System.out.println(String.format("%.2f", result));

  // ✅ Un seul appel — propre et direct
  System.out.printf("%.2f%n", result);

┌─────────────────────────────────────────────────────────────────────┐
│  NOTION 6 — List.of() et contains()                                 │
└─────────────────────────────────────────────────────────────────────┘
RÔLE :
  List.of() crée une liste immuable (non modifiable) de valeurs.
  contains() vérifie si une valeur est présente dans la liste.

SYNTAXE :
  List<String> operateurs = List.of("+", "-", "*", "/");
  boolean valide = operateurs.contains("+"); // → true
  boolean valide = operateurs.contains("x"); // → false

BONNE PRATIQUE :
  Déclarer List.of() UNE SEULE FOIS en dehors de la boucle.
  Si elle est dans la boucle, Java recrée un nouvel objet à chaque
  itération → gaspillage mémoire inutile.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

package com.rickhast.calculator;

import java.util.List;
import java.util.Scanner;

public class Main {
    static Scanner scanner = new Scanner(System.in);

    static void calculate(String operator, double number1, double number2) {
        double result = 0.0;
        switch (operator) {
            case "+": result = number1 + number2; break;
            case "-": result = number1 - number2; break;
            case "*": result = number1 * number2; break;
            case "/":
                if (number2 == 0) {
                    System.out.println("\nDivision by 0 is impossible!!");
                    return;
                }
                result = number1 / number2;
                break;
        }
        System.out.printf("%nYour operation is: %.2f %s %.2f = %.2f%n",
                number1, operator, number2, result);
    }

    public static void main(String[] args) {
        List<String> list = List.of("+", "-", "*", "/");
        double number1, number2;
        String operator, userChoice;

        do {
            try {
                System.out.print("Enter the first number: ");
                number1 = scanner.nextDouble();

                System.out.print("Enter an operator (+, -, *, /): ");
                operator = scanner.next();
                if (!list.contains(operator))
                    throw new java.util.InputMismatchException(
                        "Invalid operator. Use: +, -, *, /");

                System.out.print("Enter the second number: ");
                number2 = scanner.nextDouble();
                calculate(operator, number1, number2);

            } catch (java.util.InputMismatchException e) {
                System.out.println("\n===== Error =====");
                System.out.println("Error: " + e.getMessage());
                scanner.nextLine();
            }
            System.out.print("\nNew calculation? (y/n): ");
            userChoice = scanner.next();
        } while (userChoice.equalsIgnoreCase("y"));

        System.out.println("\nGoodbye!");
        scanner.close();
    }
}
